# Streamlit App — Додавання 10 до числа

Це простий вебдодаток на Streamlit, який:

- приймає ціле число від користувача;
- додає до нього 10;
- показує результат.

## Як запустити

1. Встановити залежності:
```
pip install -r requirements.txt
```

2. Запустити застосунок:
```
streamlit run app.py
```
